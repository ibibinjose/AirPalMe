# Fonts (self-hosted, OFL)

DM Sans (400–700 + italic) and Outfit (500–800) are served from `/fonts`
in this repo. No page loads fonts from Google Fonts or any other
third-party CDN, so visitor IP addresses are never sent to a font
provider on page load.

- Source: Google Fonts (https://fonts.google.com/specimen/DM+Sans,
  https://fonts.google.com/specimen/Outfit)
- License: SIL Open Font License 1.1 for both families
  (https://openfontlicense.org). Keep this notice with the files.
- latin subsets only. Non-latin text falls back to system fonts.
